STVARNI RADOVI

Web koji gradi povjerenje stvarnim radovima.

Umjesto generičkih stock fotografija, portfolio koristi stvarne fotografije gradilišta i izvedenih radova.

Problem

Građevinska tvrtka s većim brojem različitih usluga treba web koji posjetitelju brzo objašnjava opseg radova, gradi povjerenje i vodi ga prema upitu.

Rješenje

Web je strukturiran kao poslovni prodajni alat: od glavne poruke i procesa rada do zasebnih usluga, galerije stvarnih radova, FAQ-a i kontakta.
